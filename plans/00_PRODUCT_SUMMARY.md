# 00 — Product Summary

## Working name

ProdReady AI

## One-line pitch

ProdReady AI is an AI-powered production coding simulator where learners complete realistic engineering tickets in real repos, get guided by an AI senior engineer, pass automated checks, and leave with portfolio-ready proof of work.

## Core insight from the chat

Most coding education products teach syntax or toy exercises. The sellable opportunity is to teach how developers work in real teams:

- reading unfamiliar codebases
- fixing failing tests
- using Git and branches
- opening pull requests
- understanding CI failures
- debugging Docker/environment issues
- handling database migrations
- writing production-quality tests
- adding logging and health checks
- responding to review feedback

## Target customer

Initial customer:

- self-taught developers
- bootcamp graduates
- junior developers
- career switchers
- people who know basic syntax but lack production experience

Later customers:

- bootcamps
- coding academies
- universities
- companies onboarding junior engineers

## Positioning

Do not position this as another generic coding course.

Position it as:

> The missing bridge between tutorials and your first real software engineering job.

## First product

A single track:

**Backend Production Developer**

Stack:

- Python
- FastAPI
- PostgreSQL
- Docker
- pytest
- Git/GitHub
- GitHub Actions
- logging/health checks
- basic production debugging

## Product loop

1. Learner receives a realistic ticket.
2. Learner opens a repo/workspace.
3. Learner makes code changes.
4. Learner runs tests.
5. AI mentor gives guided help.
6. Learner submits.
7. Automated validation checks code.
8. AI gives PR-style feedback.
9. Progress/skills update.
10. Learner unlocks the next ticket.

## Core promise

Learners do not just learn programming. They learn production workflow.
