# 06 — Build Roadmap

## Phase 0 — Foundation

Deliverables:

- Repo initialized
- Next.js app
- Backend API
- PostgreSQL schema
- Auth
- Seed script
- Basic landing page
- `CLAUDE.md` and plan docs committed

Exit criteria:

- App runs locally with Docker Compose.
- Seeded track/challenges visible.

## Phase 1 — Core learning loop

Deliverables:

- Track page
- Challenge page
- Start challenge action
- Progress tracking
- Submission form
- Store repo URL/commit SHA
- Basic result display

Exit criteria:

- A user can start and submit a challenge.

## Phase 2 — AI mentor

Deliverables:

- AI chat panel on challenge page
- Challenge context injected into prompts
- Hint-level rules
- Store AI messages
- Error explainer prompt
- PR review prompt with structured JSON

Exit criteria:

- User can ask for help and receive contextual guidance.
- Submission can receive AI review.

## Phase 3 — Validation

Deliverables:

- GitHub Actions workflow in template repo
- Manual result submission first
- Backend validation record
- Parse test output
- Mark pass/fail
- Show feedback

Exit criteria:

- Challenge completion depends on validation record.

## Phase 4 — Payments and launch readiness

Deliverables:

- Stripe checkout
- Free/pro access rules
- Pricing page
- Email capture
- Basic analytics events
- 10 MVP challenges
- Demo video/landing page copy

Exit criteria:

- Product can accept paying early users.

## Phase 5 — Polished V1

Deliverables:

- GitHub App integration
- Automatic Actions status retrieval
- Codespaces links
- Improved onboarding
- Portfolio summary
- More robust admin content tooling
- More challenges

Exit criteria:

- Learner can complete the first track with low setup friction.

## Phase 6 — B2B pilot

Deliverables:

- Cohort model
- Instructor dashboard
- Learner progress reports
- Assignment deadlines
- Export CSV
- Private cohorts

Exit criteria:

- One bootcamp/training provider can pilot it.
